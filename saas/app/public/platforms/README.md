# Platform marks

`snapchat.svg` is the original two-path mark rendered in [Snap's public Ads Gallery](https://adsgallery.snap.com/?adId=3735c2a7-15ae-4c39-92b0-0f8a62a168b1), captured on 2026-10-13. Path geometry is preserved; the original page's computed black/white fills are included so the standalone SVG renders correctly. Snapchat marks are used only to identify the advertising platform. See [Snap brand guidelines](https://www.snap.com/brand-guidelines).

`google.png` retains the existing ad-library platform asset.

`facebook.png`, `instagram.png`, and `tiktok.png` are the platforms' own marks, used only to identify where an ad ran.

`youtube.png` is the original red digital icon from [YouTube's official icon download](https://brand.youtube/youtube-icon), downloaded on 2026-10-13. The PNG bytes are unchanged.

`pinterest.svg` is the original black badge from [Pinterest's official brand guidelines](https://business.pinterest.com/en-in/brand-guidelines/), captured on 2026-10-13. Geometry and the original fill are unchanged.

The same local asset paths identify the platform in both search filters and advertisement headers. Platform brand colors are preserved independently of AdThrender's black/orange interface.
