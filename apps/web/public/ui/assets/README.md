# AdTrender interface artwork

- `brand.svg` is AdTrender's existing orange vector mark.
- `antarctic-panorama.webp` is original AI-generated artwork made for the AdTrender footer on 2026-10-18. The 2132 × 737 landscape was created from AdTrender's selected original footer design and converted to WebP for delivery.
- `errors/` contains original AI-generated error-page illustrations; see `errors/SOURCE.md`.

These decorative assets contain no customer data or captured competitor artwork. Platform marks remain in `public/platforms/` with their existing source notes. No captured homepage backgrounds, advertiser catalogue snapshots or production asset manifests are included here.
