## 1. 产品目标与已确认方向

让用户在搜索广告、浏览素材、查看详情、复制文案、收藏研究时，得到一致、清楚、及时的操作反馈；让高频控件的视觉和交互精度提升到 Bencho 参考组件的水平。

用户已确认：以新仓库为开发基线；先写前台 PRD，再进入改版；前文筛选的两批组件均纳入改版。本 PRD 把“直接套用”定义为：优先取得合法可用的原始组件代码，通过薄适配层接上真实数据、权限和状态；不能只做展示页或静态外观。

本版默认：保留现有浅色暖灰与橙色品牌、导航结构、搜索参数、服务端数据及权限。主改版区域是登录后的用户工作台，官网与帮助页接入 FAQ。上述默认可在评审时调整。

### 1.1 用户与关键任务

| 用户 | 任务 | 改版后应得到的体验 |
| --- | --- | --- |
| 广告研究人员 | 按来源、国家、平台、素材等条件找广告 | 筛选清楚，条件可恢复，加载与空结果可区分 |
| 素材研究人员 | 看图、看视频、复制文案、查看来源 | 素材位置稳定，操作有明确成功或失败反馈 |
| 团队成员 | 收藏、整理文件夹、记录笔记、发起分析 | 通知来自真实结果，工作区切换后不混淆上下文 |
| 新访客 | 了解产品、数据范围及使用方式 | FAQ 易发现、易展开，手机和键盘都可操作 |

### 1.2 方案取舍

| 方案 | 收益 | 代价 | 结论 |
| --- | --- | --- | --- |

| 整站转为 Bencho 黑色、大圆角布局 | 视觉变化大 | 会扩大到品牌、布局和信息架构重做 | 本次不采用 |
| 仅给现有按钮补少量动画 | 成本小 | 无法完成完整的 8 类组件接入 | 不满足本次范围 |

- 认证、付款、套餐权益及发布部署流程不纳入此次界面改版。

## 5. 共用设计与交互规范

### 5.1 视觉适配

- 颜色优先绑定现有 `--surface`、`--ink`、`--line`、`--accent` 等 token，保留当前暖灰与橙色品牌。
- 图标继续使用 Lucide，保留已有平台标识及产品品牌；不导入 Bencho 品牌或示例照片、付费字体。
- 控件默认高度 40px；触屏主要操作热区至少 44px；小图标按钮可用透明外边距补足。
- 控件圆角 8–12px，弹层/通知 12px，业务卡片优先延续所在页面现有尺寸；不照搬展示站的大卡片空白。
- 正文与控件文字默认至少 14px，辅助信息至少 12px；一般文本对比度目标 4.5:1，控件边界及焦点指示目标 3:1，实施时实际测量。
- 交互过渡以 120–220ms 为默认区间；侧栏和分栏布局过渡最多 240ms，不以动画完成作为业务动作生效条件。
- 尊重 `prefers-reduced-motion`：关闭循环扫光、位移和弹簧，保留即时状态变化；默认不播放音效。

### 5.2 状态一致性

每个组件必须覆盖其适用的默认、悬停、焦点、按下、禁用、加载、成功和失败状态。不能只用颜色表达结果。业务请求进行中应有防重复提交行为。

所有新增用户文案进入对应语言字典。工作台与官网当前支持的语言均需补齐，并测试中文长文案、英文及其他现有语言的溢出情况。

### 5.3 上下文与降级

- 切换组织/工作区后，旧请求的通知不能显示成当前工作区的结果；按作用域隔离或丢弃。
- 浏览器禁止本地存储时，折叠和分栏仍能在当前页面操作；只是不保存偏好。
- 弹层关闭后，焦点回到触发控件；移动端不依赖 hover 才能触达主要信息。
- 空结果、网络失败、权限不足、媒体过期与未准备完成分别显示，不统一替换成空白骨架或成功通知。

## 6. 第一批需求

### F01：媒体 Shimmer 加载占位

**用户收益：** 在素材加载期间知道内容正在准备，避免卡片塌陷和重复闪烁。

**位置：** 广告卡片、详情当前素材、详情相关广告；复用同一个媒体占位实现。

**行为：**

1. 仅在已具备可尝试的媒体地址、媒体状态允许加载且当前尚未解码时显示 Shimmer。
2. 保持原媒体容器比例；宽高随容器变化，图片和视频海报均可使用。
3. 图片加载完成或视频达到现有可展示条件后隐藏占位。紧凑视频海报和无海报回退路径也要覆盖。
4. 已展示的同一资产不因刷新签名、后台重新查询或 URL 参数变化重新闪回占位。
5. `PENDING`、缺地址、失败、过期且未加载、文本广告使用各自原有说明；失败后立即停止扫光。详情保留现有超时处理，不新增长时间假加载。
6. 保留懒加载、不自动播放、手动刷新和原有签名链接策略；占位动画不触发额外网络请求。

**验收：**

- 冷缓存、热缓存、慢网、无海报视频、坏地址、已过期地址、文本广告均有明确结果。
- 加载前后媒体容器不塌陷；已加载图片在刷新签名时不闪烁。
- 同一页面多张卡片不会产生逐卡重复的读屏播报；区域统一播报加载状态。
- reduced-motion 下显示静态占位；失败与完成后均不残留循环动画。

### F02：工作台 Toast stack

**用户收益：** 收藏、整理、笔记和分析操作都有可追溯且不挡内容的反馈。

**位置：** 用户工作台单个通知宿主，由现有命令结果与局部操作接入。

**行为：**

1. 支持 success、error、info；每条记录有唯一 ID、业务对象、工作区和明确文案。
2. 桌面右下显示，移动端置于安全区内且不遮挡主操作；默认最多显示 3 条，最新一条展开，可点击或聚焦展开全部可见通知，不只支持 hover。
3. 普通成功/说明 5 秒后收起；悬停、焦点和页面不可见时暂停计时。错误保留到手动关闭；超过 3 条时可访问队列，不静默丢掉未处理错误。
4. 同一请求重复回调只产生一条通知，不同动作不可无条件覆盖。
5. 服务端成功后才报告“已收藏/已保存”。命令成功但回读失败时显示“已保存，列表刷新失败”，并提供刷新入口。
6. 分析入队显示“分析任务已提交”，任务终态被现有查询观察到后才显示完成/失败；本次不新增后台通知服务或轮询机制。若当前页面没有观察终态，只提供查看任务入口。
7. 下载只能反馈“下载链接已准备”或“已发起下载”；拿到链接不代表文件下载完成。
8. 表单错误仍留在原字段/表单附近，Toast 不能代替输入修正提示。可重试操作只复用已有安全重试入口；删除、取消、计费等动作不增加泛化的一键重放。

**验收：**

- 收藏成功、权限拒绝、断网、重复点击、笔记保存失败、任务入队和下载失败均显示与事实一致的文案。
- 同时触发 5 条通知时，队列、关闭和展开均可由鼠标、触屏及键盘使用。
- Toast 不抢焦点；普通通知使用 polite 播报，紧急错误采用适当 alert，避免反复打断。
- 切换工作区或退出登录后不残留误导性的旧操作通知。

### F03：Copy field / 复制操作反馈

**用户收益：** 确认实际复制成功，失败时仍可手动取得文本。

**位置：** 详情文案工具和原始来源链接；原始链接仍可正常打开。

**行为：**

1. 提供共用 CopyButton/CopyField；长文案沿用全文展示区域，避免把段落塞入单行输入框。
2. 点击后等待 Clipboard API 成功，再将图标转换为勾并显示“已复制”；2 秒后恢复，可重复复制。
3. 复制的是完整原始文案或经现有安全链接规则校验的原始来源 URL，不复制截断展示值。
4. 空值禁用，权限或浏览器限制导致失败时显示“复制失败，可手动选择复制”，保留可选择文本。
5. 文案或广告改变时重置状态。仅在用户触发时写剪贴板，不读取剪贴板，不复制私有下载签名地址。
6. 就地反馈为主；同一次复制不再重复弹出成功 Toast。

**验收：**

- 中文、多行、emoji、长文本和原始来源链接复制后逐字一致。
- Clipboard API 缺失或拒绝时不出现成功勾，键盘与手动复制路径可用。
- 页面跳转、连续点击、广告切换不会留下错误的“已复制”状态。

### F04：广告库 Dropdown 筛选

**用户收益：** 选项容易扫描，选中状态清楚，复杂筛选仍可准确恢复。

**位置：** 广告库当前离散值控件，包括平台、国家、状态、渠道、分类、内容等已存在且适用的字段。文本、日期、关键词及其逻辑保持现有控件。

**行为：**

1. 接入前逐项列出当前字段与选项，保留条件显示关系、后端值、默认值和提交语义。
2. 保留 `readAdSearchFilters`/`adSearchParams` 对 URL 的解析/序列化、保存筛选、清空、翻页重置和来源模式差异。
3. 沿用“选条件后提交”的现有流程，不因动效组件改成每点一次就发请求。
4. 弹层展开与收起参考 Bencho；选中项同时显示勾和文字，不只有颜色。超过 8 个选项或列表过长时提供局部选项搜索；搜索只筛本地下拉选项，不发起广告搜索。
5. 点击外部或 Escape 关闭；Enter/Space 打开、方向键移动、Enter 选择；关闭后焦点回触发器。长列表滚动时选中项可见。
6. 保留实际 form 值、关联 label、禁用/required 语义。可用原生 select 或成熟无障碍 primitive 承载，不能用仅可点击的 div 模拟。
7. 国家“来源查询条件”和“真实投放国家”的现有解释继续显示；未知/全部等值不能错误合并。

**验收：**

- 单项、多条件组合、返回详情再返回、刷新、前进/后退、已保存筛选及来源模式切换均保留正确值。
- Google 特有筛选和其他来源条件不因换控件被删除或写成错误参数。
- 鼠标、触屏和纯键盘均能选择、清空、提交与关闭；移动端弹层不超出视口。
- 替换前后相同输入生成等价查询参数；查询次数不因展示动画而增加。

## 7. 第二批需求

### F05：折叠侧栏

**用户收益：** 更多空间留给广告内容，收起后仍能识别和使用导航。

**行为：**

1. 复用现有收起状态、本地偏好和路由。文字先淡出、容器再收窄，图标定位平稳；切换期间不卸载当前页面或重发查询。
2. 桌面沿用当前展开宽度与 76px 紧凑宽度；960px 及以下继续使用现有移动抽屉，不把图标栏挤在手机页面旁。
3. 收起后为导航提供可聚焦的名称提示和完整可访问名称；当前路由高亮、帮助、账户及退出入口仍可用。
4. 保留 `aria-expanded`、抽屉 Escape 关闭、背景不可交互、焦点约束和关闭后焦点恢复。
5. 存储不可用时不抛错；窗口跨断点时不出现双导航或残留遮罩；不修改全站顶栏信息。

**验收：** 刷新记忆、连续切换、长导航名、键盘导航、手机旋转/改变宽度及禁用存储均可操作；页面内容不被侧栏覆盖，焦点不丢失。

### F06：Tab bar

**用户收益：** 当前区域明确，页签切换有连续的视觉反馈。

**位置：** 详情“概览/历史/相关广告”，研究页“收藏/分析”。

**行为：**

1. 采用 Bencho 滑动选中底板与轻量过渡，保留所有业务页签的文字，不能只展示当前项的名字。
2. 保留 `tablist`、`tab`、`tabpanel`、ID 关联及 roving tabindex；方向键/Home/End 按原有顺序切换。
3. 选中项变化立即生效，不等待动画；底板跟随文字实际宽度；长文案与窄屏可横向滚动并将选中项带入视口。
4. 沿用现有局部页签状态与查询时机，不为此次改版新增 URL 协议。广告或工作区切换时按原逻辑重置。
5. 页签切换不重复触发收藏、分析或下载；不通过给媒体区域重新加 key 导致视频无故重新加载。

**验收：** 两处页签均支持完整文字、键盘操作与 reduced-motion；选中标签、焦点和显示内容一致；不同广告和工作区不串内容。

### F07：可调整详情分栏

**用户收益：** 横图、竖视频和长文案均能获得合适的阅读宽度。

**位置：** 详情左侧素材、右侧概览/历史/相关广告；不新增全局布局编辑功能。

**行为：**

1. 大屏按现有双栏比例初始展示；左右之间加入可见、可聚焦的竖向拖动条。
2. 根据主内容容器可用宽度决定是否启用：两栏分别至少 280px 和 420px，分隔热区 16px，另计页面既有间距；不足时保持静态布局，不挤压内容。
3. 拖动只调整展示宽度，不重取数据或重建正在播放的视频；超出最小宽度时 clamp，不自动折叠隐藏业务区域。
4. 分隔条暴露 separator 语义与当前值，左右键每次调整 16px，Home/End 到边界；双击或明确的“恢复默认布局”操作复位。
5. 使用 pointer capture 支持鼠标/触控笔/触屏；拖动取消、失焦和跨断点都能清理拖动状态，不影响之后选择文本或滚动。
6. 保留现有 880px 及以下单列布局；此时隐藏分隔条并停用拖动，素材在前、信息在后。较宽窗口但主容器不足时也不得强行启用。
7. 成功调整后仅在本地保存布局比例；加载偏好时重新按当前宽度限制，存储值损坏或不可用时回默认。保存比例不包含用户、广告或工作区私有数据。

**验收：** 横/竖素材、长 URL、长标题、表格、连续拖动、键盘调节、恢复默认、宽窄屏切换和存储异常均正常；没有横向页面溢出、隐藏主操作或无故视频重播。

### F08：FAQ 手风琴

**用户收益：** 快速找到答案，展开过程清楚且不会打断阅读。

**位置：** 官网现有 FAQ 和 `/help` 全部现有问答。

**行为：**

1. 两页复用同一表现组件；保留原问答文案、顺序、链接、官网多语言及数据口径。
2. 单组最多一项展开，可再次点击收起全部；帮助页初始展开第一项，官网初始全部收起。
3. 标题整行为按钮，提供展开状态与内容关联；点击、Enter、Space 可切换，图标同步转动，答案容器平滑变化高度。
4. 高度按实际内容计算，不使用可能截断答案的固定 `max-height`；动画中快速切换不叠加错乱，关闭内容不保留可聚焦后代。
5. 切换语言、调整宽度和长答案后重新适应；reduced-motion 即时切换；不强制滚动页面。
6. 保留可由 HTML 直接读取的 FAQ 内容，不为取答案新增网络请求；套餐与效果等描述不因套组件擅自改写。

**验收：** 两页所有问答可读，展开项规则一致；链接可用，焦点和播报正确；手机及 200% 缩放无截字，长答案和语言切换不出现遮挡。

## 8. 页面组合与关键流程验收

### 8.1 广告搜索至收藏

进入广告库 → 选择多个筛选条件 → 提交 → 媒体占位 → 素材出现 → 收藏 → 真实成功通知 → 进入收藏研究页 → 回读找到对应记录。

断网/权限不足时必须保留明确失败或无法确认状态，不能显示收藏成功。过滤和侧栏切换不清空搜索条件；返回广告库保持原有 URL 上下文。

### 8.2 详情研究

从广告进入详情 → 查看素材 → 调整左右宽度 → 切换概览/历史/相关广告 → 复制完整文案 → 发起分析 → 提示已提交 → 从现有分析页查看实际状态。

素材不可用时仍可读到原文、来源与已存在事实；历史无数据时显示既有空状态，不能用演示柱状图填充。

### 8.3 导航和帮助

展开/收起桌面侧栏 → 保持当前路由与工作区 → 改为窄屏 → 打开并关闭移动抽屉 → 进入帮助 → 键盘展开 FAQ → 返回原工作台。

原有权限限制、登录跳转、工作区设置入口与未发布套餐状态均保留。
